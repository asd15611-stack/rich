# 北越空中冒險 V3.2｜純遊戲版

基於《北越空中冒險 V3.1｜台灣大富翁 V1.6.8》修改。

## 本版移除

- 整個首頁開場 Hero（「登機後，冒險開始！」）與「冒險－探索世界」頁面。
- 四張探索地圖、地圖移動／互動／寶箱／NPC／任務程式與只供這些功能使用的樣式。
- 背包頁面及其顯示／更新程式。
- 影音及飛行準備頁面、檢查表操作程式。
- 底部「冒險／遊戲／背包／影音」切換選單及處理器。

## 保留

- 首頁直接顯示「🎮 遊戲館」，十款原有遊戲入口。
- 台灣大富翁 V1.6.8（內嵌原始遊戲 HTML，不取代為示意畫面）。
- 四款益智遊戲：旅行英文挑戰、翻牌配對、九宮拼圖、迷宮尋寶。
- 五款街機：番西邦雲端跳躍、下龍灣海釣、河內街頭 BBQ、貓狗大戰、敲鞋跟。
- 遊戲成就顯示、街機原始本機記錄、台灣大富翁原始本機存檔與備份功能。

## 存檔保護

- 不呼叫 localStorage.clear / removeItem；不刪除或覆寫 V3.1 冒險資料鍵 `northernVietnamAirAdventureV1`。
- 遊戲成就讀取舊冒險成就，新的成就另存於 `northernVietnamAirGamesWinsV1`。
- 街機 `northernVietnamAirArcadeV2` 及大富翁內嵌程式原來的儲存鍵維持不變。
- 注意：不同網址、瀏覽器或以檔案方式開啟，可能無法直接分享同一組 localStorage；跨來源沿用大富翁存檔應用其 JSON 備份匯入。

## 驗收

- Chromium 手機 390×844：26 項 UI 操作檢查通過。
- Chromium 桌面 1280×900：26 項 UI 操作檢查通過。
- 四款益智遊戲：全部可打開對話框並關閉。
- 五款街機：全部可開啟介面並返回遊戲館。
- 台灣大富翁：內嵌 iframe 成功載入 `#goBtn`，可開啟及關閉。
- 未顯示已移除頁面、遊戲按鈕共十張；沒有偵測到頂層 JavaScript 執行錯誤。
- 額外隔離測試：模擬 V3.1 已有兩款遊戲成就，V3.2 可以讀取並顯示兩枚獎章。
